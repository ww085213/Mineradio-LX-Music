# Mineradio 1.6.0

Mineradio 1.6.0 的核心更新是 AI Agent“小M”。它不只是聊天窗口，而是可以调用播放器工具、控制软件界面和修改设置的桌面音乐助手。

## AI Agent 小M

- 新增可拖动的小M悬浮球、对话面板、思考/执行状态和高级设置。
- 支持自然语言搜索并播放歌曲、重新播放、播放/暂停、上下曲、调整音量、跳转进度和切换播放模式。
- 支持切换标准、极高、无损等音质，并打开音质选择面板。
- 支持打开音乐库、音乐电台、平台排行榜、音源管理、输出设备、热键、高级设置等 Mineradio 界面。
- 支持控制歌词动画、DIY 视觉效果和桌面相关功能。
- 支持把歌曲或歌单加入队列、保存歌曲、创建本地歌单和生成推荐歌单。
- 支持 OpenAI、Claude、Gemini、DeepSeek、通义千问、Kimi、Ollama 和自定义 OpenAI 兼容接口。
- API Key 仅保存在当前用户本机，不随项目上传或内置在安装包中。
- 支持窗口内 `Alt+A` 与全局 `Ctrl+Alt+A` 唤起；可在高级设置中隐藏悬浮球。
- 支持可用环境下的 Windows 语音识别或本地 Whisper 辅助输入。

## 体验与彩蛋

- 对小M说“世界和平”可触发经典登录彩蛋效果。
- 修复清除对话记忆后输入框一段时间无法点击、无法输入的问题。
- 助手名称统一为“小M”，不再显示旧称“矿灵”。
- 补齐音乐库、电台、排行榜、音质、歌词动画等界面的工具映射。

## 安装与升级

- 使用 Mineradio 定制安装向导，可选择安装目录并创建快捷方式。
- 覆盖升级前会先正常关闭正在运行的 Mineradio；若仍有残留进程会自动清理，避免出现 `Mineradio.exe` 无法写入的错误。
- 保留 `%APPDATA%\Mineradio` 中的歌单、设置、用户数据和小M本地配置。
- 支持 Windows 10/11 x64。

## 使用提示

- 在线 AI 模型通常需要用户自行申请 API Key，并可能由相应服务商计费。
- Ollama 等本地模型服务不要求云端 API Key，但需要用户自行安装和运行模型服务。
- 在线音乐搜索、登录、歌词和第三方平台内容仍取决于网络、账号状态与第三方接口可用性。
